# To Do List and Address Book

#### A simple web application for managing your tasks and contacts, 2nd May 2025
#### By **Jeremy Amani**

## Description

Tired of juggling tasks and contacts across scattered notes and apps?  This application is your all-in-one solution!  It's a dual-purpose web application designed to help you organize your life.  First, it's a To Do List that empowers you to add, mark as done, and remove tasks, ensuring you stay on top of your daily activities and boost your productivity.  Second, it's a basic address book to manage your contacts.

Links:
* GitHub Repository: [https://github.com/JxAmani/to-do-list.git](https://github.com/JxAmani/to-do-list.git)
* Live Demo: [https://to-do-list-gamma-teal.vercel.app/](https://to-do-list-gamma-teal.vercel.app/)

## Setup/Installation Requirements

* To use this application, you only need a web browser.
* No additional software or setup is required. Simply open the `index.html` file in your browser.

## Known Bugs

* Currently, there are no known bugs.

## Technologies Used

* HTML - for structuring the web page.
* CSS - for styling the web page.
* JavaScript - for implementing the interactive functionality (adding, marking as done, and removing tasks).
